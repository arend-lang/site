The paper [Theorem prover Arend](/assets/lang-paper.pdf) is now finished. It touches the following topics:

* Homotopy type theory with an interval type (HoTT-I) and its extensions in Arend.
* Universe polymorphism, homotopy levels, classes and records.
* The IntelliJ Arend plugin.
* The Arend command-line interface and LLM-assisted formalization.
* The library [arend-lib](/arend-lib).
